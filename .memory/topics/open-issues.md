# Open issues

Each entry says what is wrong, where it is, and the next step. Nothing here is
finished work.

- 2026-10-20 — **The `tier` run argument means two different things.** The hub sends the depth-tier id (`"fringe"`, `"wilds"`, …) under `args["tier"]`, but the old map picker sends the difficulty number (`0`–`3`) under the same key. So `scripts/run_screen.gd:197` reads `"0"` as a tier id and `scripts/run_screen.gd:219` reads `"fringe"` as a difficulty (it becomes 0). Both flows are wrong today. Next step: give difficulty its own key (`args["difficulty"]`) and update `scripts/app.gd:878` and `scripts/world_screen.gd:193`.
- 2026-10-20 — **A tier hunt does not clear its tier.** `SaveGame.clear_tier()` exists but nothing calls it, so the gate above a cleared tier never opens. Next step: call it from the `boss_down` branch of `scripts/run_screen.gd`.
- 2026-10-20 — **The tier entry can miss its band.** `HuntMap.entry_for_tier()` looks for a `clearing` node in the band's southern row, but the abyss band is the lair row, so it falls back to the world start. Next step: take the node in that row whatever its kind is — prepared but not yet run in `tools/pending_tier_fix.py`.
- 2026-10-20 — **The run still plays the old whole-world map.** The per-tier `ZoneBuilder` zones exist and are checked by `tools/zone_check.gd`, but `RunSim` builds `HuntMap.world`, so a tier hunt is the old map with tier-scaled monsters. Next step: build the zone for the tier and let the run play it; the stage ground grid is currently hard-wired to `HuntMap.WORLD_ROWS/WORLD_COLS`.
- 2026-10-20 — **The bot cannot clear the meadow.** The full sim-check ends in seven failures, all of them the meadow bot fights: sorceress, rogue and barbarian each lose the meadow at exactly 119.0 s (outside the 2.5–5.5 min window the check wants) and the full seeded bot run ends in a loss. These failures pre-date this work (they failed with ember, juniper and pebble as well). What we know: 119 s is the shared hunt clock (`HUNT_LIMIT`), the lair boss rises at 68 s (`EXPLORE_BOSS_AT`), and the whole-world map is 4480×8960 sim px, so a fresh hero has 51 s to fight a boss it has to reach on foot. Next step: decide whether the meadow is too hard for a fresh hero, the walk is too long, or the bot steering is too passive — and note that the per-tier zones are 2560 px tall instead of 8960, which would also shorten that walk.
- 2026-10-20 — **The README still describes the old game.** It opens with "from home, open a biome", lists the old critter ids as the playable cast and describes only three roles (Mage, Archer, Tank), while the playable roster is now barbarian, paladin, sorceress, rogue, necromancer, druid and the camp is the front door. Next step: rewrite the Play section once the camp flow is settled.
- 2026-10-20 — The boss-intro check counted hits that landed after the reveal; it now only counts a hit or an attack that landed while the boss was still in its intro, and the check passes — `scripts/sim_check.gd`
- 2026-10-20 — Scratch files are cleaned up: `tools/_fix_intro.py` (already applied), `tools/_test_intro.gd` and `tools/_test_intro.ps1` (a headless probe that hung) are gone; the unrun tier patch now lives at `tools/pending_tier_fix.py`

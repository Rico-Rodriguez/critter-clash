# Credits

Critter Clash is an original game. The hunt, the roster, and the interface are original. Placeholder critters and arenas are painted by a script in this repo so the real sprites can replace them later by filename. Nothing in the game changes a critter's role based on where it stands.

## Code and engine

- Godot Engine 4.7.2 — https://godotengine.org — MIT License.

## Pictures

- `assets/sprites/` is generated by `tools/build_sprites.py`. These are temporary stand-ins, not third-party character packs.
- `icon.png` is drawn by `tools/make_icon.py`.

A later art pass will drop hand-painted PNGs onto the same paths. The expected sizes are listed in the README under "Sprite drop-in".

## Audio

- Effects and the music loop are synthesized by `tools/build_audio.py`.
- No sampled libraries and no third-party tracks.
